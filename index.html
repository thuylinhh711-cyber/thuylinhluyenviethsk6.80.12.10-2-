Tại sao chunking hiệu quả? Mắt học nhảy theo cụm ý thay vì từng chữ. Khi nhận ra 不得其解 là một cụm thay vì 4 chữ rời, tốc độ tăng 3–4x. Từ 2s/cụm → 0.4s/cụm theo từng cấp độ.

📄 Lưu cả app thành file HTML
Tải về 1 file .html chứa toàn bộ mã nguồn app + dữ liệu hiện tại (bộ thẻ, ghi chú, tiến độ, cài đặt). Giữ file này làm bản gốc: mở lại là còn nguyên, và có thể chuyển sang máy khác.
📤 Xuất dữ liệu
Tải xuống bộ thẻ, ghi chú, tiến độ và cài đặt dưới dạng file .json — dùng để sao lưu hoặc chuyển sang máy/trình duyệt khác.
📥 Nhập dữ liệu
Chọn file .json đã xuất trước đó. Dữ liệu sẽ được gộp vào — bộ thẻ trùng tên được đổi tên tự động, ghi chú và tiến độ được cộng dồn, không xoá dữ liệu hiện có.
